# ✨ Paigen — Your Personal Web Space

A multi-page website designed to bring together everyday digital experiences in one place. **Paigen** is a web development project featuring different sections for chatting, news, reels, videos, and weather.

## 🌷 About the Project

Paigen is a personal website project built to explore web development, interactive user interfaces, and multi-page website design. It brings several useful web experiences together through a single project.

## ✨ Features

- 💬 **Chat** — A dedicated chat page.
- 📰 **News** — A separate space for news content.
- 🎞️ **Reels** — A page for short-form video content.
- 📺 **Videos** — A dedicated video page.
- 🌦️ **Weather** — A weather page.
- 🎨 **Custom Styling** — Shared styling using CSS.
- ⚡ **JavaScript Functionality** — JavaScript for website interactions.

## 🛠️ Tech Stack

- **HTML5** — Website structure and pages
- **CSS3** — Styling and layout
- **JavaScript** — Interactivity and functionality
